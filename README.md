# Cursos de Node.js

Este repositorio contiene ejemplos y ejercicios prácticos del curso de Node.js.

## Contenido

- Transcripción de audio con AssemblyAI
- Uso de módulos de Node.js como fs, path, axios, etc.
- Integración con APIs externas
- Ejercicios prácticos de manejo de archivos y peticiones HTTP
- Como publicar un recurso en "npm" y como utilizarlo

## Cómo usar

1. Clona el repositorio
2. Instala las dependencias con `npm install`
3. Ejecuta los scripts con `node nombre-del-archivo.js`
